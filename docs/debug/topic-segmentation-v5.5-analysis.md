# 话题分割 v5.5.0 实施报告

## 三条路径

| 路径 | 名称 | 触发条件 | 行为 |
|------|------|---------|------|
| 1 | CJK 渐进合并 | prev.todo CJK 字与 curr.core_change/new_materials CJK 字交集 ≥3 | 链内/入口合并 |
| 2 | 强制话题切换短语 | core_change 首 30 字匹配短语模式 | 无条件分裂 |
| 3 | 水位压力 | 累计 Fct 字段字符数 > 8K，j 线性扣减 → 16K 时扣 0.30 | effective_j < 阈值 → 分裂 |

## 关键变更

| 变更 | 旧 | 新 |
|------|----|----|
| todo 重叠检测 | `prev_todo & curr_core` 精确字符串匹配（≥1 匹配） | CJK 单字集合交集（≥3 共享字） |
| 合并路径 | 3 条（含 Jaccard 独立合并） | 2 条（去掉独立合并） |
| BG 处理 | BG 轮参与话题分配（连续 BG 合并、BG↔实义分裂） | BG 轮排除，不参与任何话题运算 |
| 自适应阈值 | `_load_start_threshold` → `persist_ideal_threshold` | 全部删除 |
| ENTRY 阈值 | 0.03 | 0.02 |
| 水位区间 | 无（不存在） | 8K ~ 16K，线性扣减 j |

## 短语模式（路径 2）

```
换.*[话题|个]|换个话题       — "换一个话题""换个话题"
换[个|点|别的]              — "换别的""换点别的"
另一个[话题|问题]           — "另一个话题"
聊点别的
说回.*

别提[了那这]
不管[了那这]|不管[了]?[个这]          — "不管了""不管这个"
```

## 水位压力公式

```
progress = clamp((accumulated - 8000) / (16000 - 8000), 0, 1)
effective_j = raw_j - progress × 0.30
```

| 累计 Fct | 压力 | effective_j 扣减 | 效果 |
|----------|------|----------------|------|
| ≤ 8K | 0.0 | 0 | 无影响 |
| 10K | 0.29 | -0.09 | 同话题（j≈0.25）→ 0.16 仍合并 |
| 14K | 0.86 | -0.26 | 同话题（j≈0.20）→ -0.06，分裂 |
| ≥ 16K | 1.0 | -0.30 | 几乎必分裂 |
