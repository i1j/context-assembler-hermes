# SYS-001: `set_system_overhead()` 已移除 (2026-06-14)

---
**父节点:** [[R-000]]
---

**Parent:** R-000

**Context:** 测量范围仅覆盖 content 字面量~9.5K, 但实际系统开销含 tool schemas(~20-30K tok) + response_format + tokenizer 框架(~3-10× 低估)

**Decision:** 删除插件层 `set_system_overhead()` 测量代码 (原扫描 conversation_history 中 role=system 的 content 长度)

**Evidence:** design/system-overhead-measurement-analysis.md

**Root cause:** `tools` 参数是 API 独立顶层参数, 不在 messages 结构中, CA 永远无法准确测量

**Effect:** `_system_overhead` 保留默认值 20000 作为保守缓冲区; Middle Hdl 永远生成不受预算约束; 真正的输出上限由 `_hard_truncation()` 保障
