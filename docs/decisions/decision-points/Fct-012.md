# Fct-012: 移除 `<core_change>` 内部标签清洗 (v1.2 ADR-02)

---
**父节点:** [[Fct-001]]
---

**Parent:** Fct-001

**Context:** 研发对话中高频出现 XML 标签和泛型参数(如 `<model>`), 过度清洗导致真实技术细节被静默误杀

**Decision:** 彻底移除 KNOWN_HALLUCATION_TAGS 清洗逻辑, 保留 `WHITESPACE_PATTERN.sub(' ', ...)` 只做空格压缩

**Evidence:** ca-l1-refactor/ca-l1-whitepaper-v1.2-gm.md ADR-02
