# RF-001: 术语重命名 Elm/Fct/Hdl, F-stage (v5.0 Phase 1)

**Context:** OpenViking 继承的 Elm/Fct/Hdl 三层命名（原名 L2/L1/L0）未区分"原始数据"与"已处理数据"的概念。C-stage 命名暗示"压缩"而非"摘要生成"

**Decision:**
| 旧名 | 新名 | 含义 |
|------|------|------|
| L2 | Elm | 原始数据 (Element) |
| L1 | Fct | 事实数据 (Fact) |
| L0 | Hdl | 数据标题 (Handle) |
| C-stage | F-stage | 事实阶段 (Fact) |

方法重命名：`_run_c_stage` → `_run_f_stage`, `_call_llm_for_l1` → `_call_llm_for_fct`, `_update_l1_v5` → `_update_fct_v5`, `L1TruncatedException` → `FctTruncatedException`。DB 列名 `l1_text`/`l0_text` 保持原名，Python 层用别名访问。

**Evidence:** changelog v5.0 Phase 1, commit `260000d`, F-stage 实施记录 debug-2026-06-15-f-stage-impl.md
