# RF-004: thought 截断修正 — 句子边界 (v5.0 Phase 4)

**Context:** `generate_group_summary()` 旧逻辑遍历句尾分隔符列表找第一个句号就返回，且仅当 ≤90 字时才截断。文本长度稍超 90 但第一个句号在 10 字处时会返回极短摘要，信息密度低。无句尾标点的长文本无法被截断

**Decision:** 按句子边界累加，超 100 字时含当前句返回：
```python
# 旧: for sep in (句尾标点列表): find(sep) → cut ≤90 返回
# 新: re.split(r'(?<=[。！？.!?])\\s*', text) → 逐句累加
#     len(result) + len(s) > 100 and result → 含当前句返回
```
效果：句子1(30字) + 句子2(50字) + 句子3(40字) → 累计120 > 100 → 返回全部 3 句。
