# ES-002: turn_stream (turn,seq) 统一坐标 (v5.0 简化版)

**Context:** 旧 v4/v5 hybrid schema 混合主键（turn_type / tool_sub_index / l2_text / api_call_count 等多列），历史债积累过重。conv_encoding 分离表增加 join 开销

**Decision:** 全线重写：
- `PRIMARY KEY (session_id, turn, seq)` — 唯一身份，不引入辅助键
- 统一存储 role/content/tool_name/tool_call_id/status/duration_ms/tool_calls_json/finish_reason/usage/biz_category/l1_text/l0_text
- 删除 `turn_type` / `l2_text` / `tool_sub_index` / `api_call_count PK` / `conv_encoding` 表
- 不向后兼容

**Evidence:** changelog v5.0 简化版, commit `5432463`, CA_v5.0_架构设计_20260614.md
