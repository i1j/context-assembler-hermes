# ES-001: E-stage 写即落盘替代内存 buffer (v5.0 简化版)

**Context:** 旧 `_tool_buffer` / `ToolGroupBuffer` 缓存工具行后批量写入，导致以下问题：
- `(turn, seq)` 语义碰撞：per-api-group vs per-turn key 被后一组覆盖
- 线程安全问题：并发读写 buffer 缺乏可见性保证
- 编码表因线程安全问题从未生效

**Decision:** 每条原始数据到达钩子时立即写入 `turn_stream` 表，不经过内存 buffer。
- `pre_llm_call` → 写 seq=0 (user)
- `post_api_request` → 写 seq=1 (thought + tool 占位行)
- `post_tool_call` → 回填 tool 行 + per-tool Fct
- `post_llm_call` → 写 assistant_fin + 启动 F-stage
删除 `_tool_buffer` / `ToolGroupBuffer` / `flush_tool_buffer()` 全套

**Evidence:** changelog v5.0 简化版, commit `5432463`
