**父节点:** [[R-000]]

**Parent:** R-000

**⚠️ 历史纠正 — CR-007 回退:** 本决策的 §5（断路器状态文件）被误删除。断路器状态文件（`_record_failure`/`_record_success`/`is_available` 等 8 个函数，约 90 行）被 `2c4e34b` 一并移除，但 plugin 中仍保留了 `is_available()` 调用。结果 `on_session_start` 调用 `_record_success()` → `NameError` → `_engine=None` → 所有 E-stage hooks 跳过。由 CR-007 于 2026-06-20 修复。详见 [[CR-007]]。

**Tests:**
  - 所有保留测试全量通过（`pytest -n 4`）
  - `grep -r` 确认被删标识符无残留引用
  - 语法检查（`python3 -c "import ca"` 来自插件启动路径）
