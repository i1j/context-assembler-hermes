# Fct-005: 截断检测双重校验

---
**父节点:** [[Fct-001]]
---

**Parent:** Fct-001

**Context:** 部分 LLM API 达到 max_tokens 时错误返回 `finish_reason='stop'` → 靠单一路径防不住
Action: 任一触发 → 抛 L1TruncatedException → C-stage 写 `_assemble_status=1` 待补全

**Decision:** 每次 LLM 返回后做双重校验: `finish_reason=='length'`(API 截断) + `endswith('</core_change>')`(物理边界)
