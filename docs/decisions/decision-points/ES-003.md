# ES-003: _simple_mutation_mode 跳过 cache 层 (v5.0 简化版)

**Context:** 旧 `_mutation_mode` 依赖四层链路：`_build_aligned_outcomes` → cache(`AssemblyCache.tool_l1_texts`) → 编码表 → `_compute_tool_plan_v2`。其中 cache 的 tool key 存在 `(turn,seq)` 碰撞，编码表因线程安全从未生效。旧路径同时依赖 `turn_plan` / `tool_plan` / `bypass_turns` 等复杂状态

**Decision:** 新增 `_simple_mutation_mode`，直接从 DB 查询 Fct：
- `store.read_turn_texts(sid, turn, 'tool_group', tool_group_api_count=N)` — DB 原生 `(turn, api, seq)` 精确过滤
- `store.read_tool_rows_for_group(sid, turn, group)` — 同上
- 尾部保护区：最后 3 个 user 消息之后全部原文保留
- 不依赖：turn_plan / tool_plan / bypass_turns / AssemblyCache / _conv_encoding / bg_review 特殊处理

**Evidence:** changelog v5.0 简化版, debug-2026-06-15-simple-mutation.md
