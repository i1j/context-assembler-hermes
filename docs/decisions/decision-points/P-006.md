# P-006: bg_review 内容清空（mutation 尾区保护）

---
**父节点:** [[P-001]]
---

**Parent:** P-001

**Decision:** `_mutation_mode` 中，bg_review 轮的 content 在非尾区位置清空为单空格 `" "`；尾区（最后 2 非 bg_review 对话轮 + 当前 Q）内的 bg_review 行保留原文。

**Alternatives considered:**
1. 第二遍全量扫描 + `bypass_turns` Set 匹配
2. 合并入 mutation 主循环 + 位置计数边界（选定方案）

**Evidence:** `plugins/ca_assembler/__init__.py` — `_mutation_mode()` 中 `outcome is None` 分支条件判断；`docs/debug/debug-20260612-bg-review-content-cleanup.md`

**Implementation note:** 从后往前数非 bg_review 的 user 轮确定尾区边界，保护 `_tail_boundary` 之后的所有消息（含 bg_review）原文保留。

**Tokens:** 清理后的 bg_review 行每行 8 tok（user/assistant）或 32 tok（tool），零信息。骨架不可删（共享 dict 引用限制）。
