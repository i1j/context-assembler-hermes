## 背景

空壳阶段不修改消息内容，仅验证接管 `_compress_context` 和包装 `_persist_session` 的管道是否通顺。所有红线的验证都在这一关完成。

## 架构

### `_ca_compress(messages, system_message, ...)` — 替换 `_compress_context`

```python
if session_id in _compressed_flag:        # 防二次触发
    return (messages, system_prompt)

_saved_originals[session_id] = [dict(m) for m in messages]  # ①存原始
_saved_short_len[session_id] = len(messages)                 # ②记长度
_compressed_flag[session_id] = True                          # ③设标志

return (messages, system_message or "")   # ④原样返回（空壳）
```

### `_ca_persist(messages, conversation_history)` — 包装 `_persist_session`

```python
if session_id in _saved_originals:
    originals = _saved_originals.pop(session_id)
    short_len = _saved_short_len.pop(session_id)
    appended = messages[short_len:]         # LLM 新回复
    full = originals + appended            # 恢复长表
    return _original_persist(full, ...)    # 写 state.db

return _original_persist(messages, ...)    # 直通
```
