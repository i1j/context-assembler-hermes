# TP-007: 话题管理器故障安全降级

---
**父节点:** [[TP-001]]
---

**Parent:** TP-001

**Decision:** `_topic_mgr` 初始化失败（embed 不可用 / DB 异常）→ None → 全线 ACT 降级，不 crash

**Evidence:** `__init__.py` L425 (tester profile); tests/unit/test_topic_manager.py; tests/stage/test_a_stage_topic_aware.py

**Tests:**
  - `tests/stage/test_a_stage_topic_aware.py` — `test_no_topic_mgr_all_act`, `test_plugin_mgr_none_safe`, `test_embed_failure_fallback`
  - `tests/unit/test_topic_manager.py` — `test_centroid_none_fallback_rel`, `test_embed_failure_sets_none_centroid`, `test_no_query_embed_defaults_rel`

**Detail:**
- `self._topic_mgr = None` → 所有 turn 按 `TopicGrade.ACT` 处理
- 代码: `topic_grade = self._topic_mgr.get_turn_grade(...) if self._topic_mgr else TopicGrade.ACT`
- embed 返回 None/抛异常 → `_compute_centroids()` 产生 None centroid → `_grade_topics_by_radius` 退到 REL fallback
- embed 故障时非 bg turn 走 REL, bg 走 FAR
- 不影响替换管线正常执行：降级是 lossy 但不 crash
