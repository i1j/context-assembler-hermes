# CR-006: FAR thought/tool 替换为 "略" 而非空串 (2026-06-20)

---
**父节点:** [[R-000]], [[TP-002]]
---

**Parent:** R-000, [[TP-002]]

**Problem:** FAR 等级 thought/tool 替换为 `""` 空串，LLM 收到空白消息可能产生奇怪的语义行为

**Fix:** 改为 `"略"` — 语义明确的省略标记，与空串「原文缺失」语义区分

**Rationale:** 与硬截断 `[工具调用结果因上下文截断已被省略]` 类似的设计哲学 — 用显式 sentinel 而非空白

**Effect:** LLM 接到的是有意义的「略」字而非空白，行为可预测

**Evidence:** ca/__init__.py (thought/tool FAR 分支 2026-06-20); tests/stage/test_a_stage_topic_aware.py (3 处测试同步，assert content == "略")

**Tests:** 134 passed (test_topic_manager + test_grade + test_a_stage_topic_aware + test_a_stage)
