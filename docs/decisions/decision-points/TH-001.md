# TH-001: 组件级锁策略表

---
**父节点:** [[R-000]]
---

**Parent:** R-000

**Decision:** 各组件使用独立锁策略, 避免全局锁竞争:

| 组件 | 锁 | 用途 |
|------|-----|------|
| SQLiteStore | threading.local() | 每线程独立连接 |
| BM25Okapi | RLock | index/doc_lengths |
| AssemblyCache 数据 | RLock | dict 保护 |
| AssemblyCache 快照 | 独立 RLock | snapshot 原子替换 |
| SessionManager | RLock + Condition | 异步销毁 |
| EmbeddingClient LRU | RLock | 线程安全 |
| _pending_tasks | Lock | task 管理 |
| _pre_upgraded_tool_turns | Lock | C→A 跨阶段 |
| _rebuild_future | Lock | 单重建任务 |
| _retry_timer | Lock | 避免竞态 |

**Evidence:** ca/cache.py, ca/store.py, ca/embedding.py, ca/__init__.py
