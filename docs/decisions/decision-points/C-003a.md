**Context:** 事故 CA-2026-002 — 所有环境 100% fallback (~190+ turns 为零有效 Fct)

**Evidence:** ca-l1-fallback-investigation.md; ca-v4.3.2-incident-report.md (P0#1); ca/config.py L54

**Root cause:** `_call_llm_for_l1` 硬编码 `num_predict=512` → Qwen3 thinking 消耗 2000+ tokens → response 字段留空 → 重试 2 次后 fallback

**Fix:** 从 512 增至 24768, 通过 Config.LLM_NUM_PREDICT 可配置注入 (env CA_LLM_NUM_PREDICT)
