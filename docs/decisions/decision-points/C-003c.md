# C-003c: OODA 文本 vs JSON (妥协方案，OODAParser 已移除)

---
**父节点:** [[C-003]]
---

**Parent:** C-003

**Context:** Qwen3 JSON 输出成功率 <60%, 经常空串; OODA 文本格式稳定 >95%
Trade-off: 降低了格式精度要求, 释放 thinking 给内容本身; 预留 JSON 切换路径 (prev_l1 兼容两种格式)

**Decision (v4.4.0, superseded):** LLM 输出 OODA 五节自然语言文本 → 代码 `OODAParser` 解析为结构化 JSON

**Current (v4.7.0+):** `OODAParser` 已删除，由 `parse_v1_markdown_xml()` 直接解析 Markdown+XML 输出为结构化 l1_dict。
参见 [[L1-001]] (PDD)、[[L1-004]] (parse_v1_markdown_xml)。

**Evidence (historical):** changelog v0.2 (2026-05-17); development-report.md; prompts.py (L1_GENERATION_PROMPT)
