# Fct-003: CA_L1_TEMPERATURE / CA_L1_MAX_TOKENS — 独立配置

---
**父节点:** [[Fct-001]]
---

**Parent:** Fct-001

**Context:** 旧方案所有 LLM 调用共用 num_predict=24768 → 对 Fct 摘要过于宽松; Fct 只需 200-600 token

**Decision:** Fct 生成使用独立 temperature(默认0.3) 和 max_tokens, 不再共用 LLM_NUM_PREDICT(24768)

**Evidence:** ca/config.py (tester profile); ca-l1-refactor/ca-l1-refactor-requirements-v2.md REQ-2~4

**Detail:** validate 校验范围 [0.0,2.0] 和 [50,4096]; reload 热重载支持; env CA_L1_TEMPERATURE / CA_L1_MAX_TOKENS

**默认值变更（v6.0.2）:** v6.0.2 从 800 提升至 2048。原因：实际成功 Fct 可达 1,382 chars（~1,382+ tokens），800 不足以覆盖多 changes + Markdown 叙事段 + JSON 结构开销的典型场景。2048 在验证范围 [50, 4096] 内。
