# RF-003: stage_tag 独立 XML 标签 (v5.0 Phase 3)

**Context:** 旧 prompt 将状态前缀 `【已实施】` 内嵌在 `<core_change>` 内容中，`_extract_l0` 从 core_change 首句截断取状态，解析不稳定。状态与内容耦合导致 Hdl 提取和 Fct 解析相互干扰

**Decision:**
- 新增独立 `<stage_tag>` 标签存放状态
- `<core_change>` 只含内容不含状态前缀
- `post_process.py` 新增 `STAGE_TAG_PATTERN` 正则提取
- `parse_v1_markdown_xml` 将 stage_tag 写入 `l1_dict["stage_tag"]`
- `clean_increment` 保留 stage_tag 到 cleaned 输出
- 移除旧的 `parse_core_change_state()` 处理

示例：
```xml
<stage_tag>已实施</stage_tag>
<core_change>临时扩容数据库连接池至200</core_change>
```
