# RF-002: F-stage 从 DB 读 Elm (v5.0 Phase 2)

**Context:** 旧 `process_turn_async` 接收 `user_message`, `assistant_response`, `conversation_history` 三个参数，将 Elm 文本从调用方拼接传递，与存储层耦合过紧

**Decision:** F-stage 只接收 `turn_index`，所有 Elm 数据从 DB 读取：
- 新增 `read_turn_elm_rows(store, session_id, turn)` — 返回各 seq 的原始 content
- 新增 `read_prev_fct(store, session_id, turn)` — 读取前轮 seq=0 的 Fct
- 移除函数参数中的 `user_message`/`assistant_response`/`conversation_history`
- 调用签名：`process_turn_f_stage(turn)` 替代 `process_turn_f_stage(user_message, assistant_response, history_copy)`

**Evidence:** changelog v5.0 Phase 2, commit `6e1bfe5`, F-stage 实施记录
