**v6.4.2 补充（2026-08-01）**：`LLM_NUM_PREDICT=24768` 是 F-stage 参数，但话题摘要链路
（`call_llm_for_summary`）此前复用 `L1_MAX_TOKENS=2048`——多 strand 输出（实测 ~2538 字符）
被 2048 token `stop=length` 截断 → JSON parse 失败 → 批量重跑 46% 走代码 fallback。
