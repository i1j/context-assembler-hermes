## 一、背景与问题（数据实证）

### 1.1 注入侧余弦正向检索失效（上轮基线，winker 46 strand）

| 模式 | 命中率 | 噪声率 | 判定 |
|---|---|---|---|
| reality 库 + 余弦 top-3 注入 | 0.000（0/9） | 1.000（30/30） | 注入完全失效 |
| legacy 大而全 theme | 命中虚高 | 噪声过半 | 不可用 |

根因：余弦测不出"工作关联"（R1×R35 共现 3 次、词面零重叠）；reality 粒度下 centroid 表达失真。

### 1.2 merge 侧 sim 门槛同样失效

- P4（决策 37 §1.2）：strand kNN P50=0.40（sim 0.60），0.70 门槛与 reality 粒度脱节——该归的 reality 进不了候选
- 术语误合风险：≥0.70 区间假相似多于真重叠，放松阈值候选对激增 25 倍

### 1.3 金标准数据污染（本次会话发现）

winker 34 个 reality 由本地 4B 生成，**碎片化严重**：29/34 单 strand；同一工作线被切碎（内存压缩 R17/R19、孤儿清理 R35/R36、中文 header 问题链 R4/R5/R15、显存/上下文优化 R46/R47/R48、模型文件管理 R10/R12/R43）。碎片化导致：
- 共现边退化（星型结构，R1 独有 24 邻居/34）
- 权重实验全部失真（α/β 全组合无差异）
- PMI 全负不可用（N=11 块过小）

### 1.4 根本目的（与决策 37 一致）

**切换话题提问时提供有效背景**。注入利用率是端到端目标，归并/检索是中间手段。注入与归并必须**同一尺度**（统一度量，用户偏好）。

## 二、核心概念（用户确认）

| 概念 | 定义 |
|---|---|
| **共现边** | 历史同话题块中一起出现的 reality 对，边权 w = 共现次数（行为信号，非语义） |
| **距离** | d(a,b) = 1/(PMI(a,b)+1)，PMI ≤ 0 → ∞（反相关/偶然共现排除） |
| **S 匹配分** | 候选 reality 到锚点集的加权平均图距离 |
| **per-anchor 权重** | 每个 reality 作为锚的可信度（注入 0.4 / 融合 0.8 / 精炼轮可调） |
| **空注入** | 4B 拣选允许输出空集（全新话题不产生错误锚） |

**核心转向（用户拍板）**：**彻底抛弃 sim 思维**——向量只做注入侧入口定位的负向排除，merge 侧候选/排序/排除全用共现图行为信号。

## 三、图模型定义

```
图 G = (R, E)：
  节点 R = realities
  边 E(a,b) 权重 w(a,b) = 历史同话题块共现次数（块归并完增量 +1）
  边距离 d(a,b) = 1/(PMI(a,b)+1)，其中 PMI = log(w·N / (deg_a·deg_b))
  无正 PMI 边 → d = ∞（不连）
```

**PMI 归一化动机（实测）**：原始 w 下枢纽节点垄断候选池——R1 权重 27、邻居 24/34（母体工作线几乎与所有 reality 共现）。PMI 压低"跟谁都共现"的偶然边，突出特异性共现。实测 R1×R35 (w=3) PMI=-2.197 仍为负——**当前 N=11 块数据量下 PMI 区分度不足，需数据积累**（w 与 PMI 双轨保留，数据充足后切 PMI）。

## 四、注入侧流程（切换时）

```
提问 → ① 向量负向排除（d>0.55 剔除，仅缩小 4B 输入）
     → ② 4B 拣选锚点 top-3（工作关联判定，允许空集 = 空注入）
     → ③ 共现球扩展（锚点邻域距离 ≤ R）
     → ④ 注入集 I = 锚点 ∪ 球内（预算截断）→ 快照 candidate_themes
```

- ③ 待定：当前阶段先纯 4B 锚点（球扩展依赖共现图数据积累）
- 空注入（用户确认）：全新话题 → 4B 输出 [] → I=[] → merge 走 new → 新建 reality → 块内 F 累积冷启动。**宁缺勿错**（P5 先例：4B 硬选产生幻觉越界）

## 五、merge 侧流程（话题块结束，时间序流式）

```
strand N 候选：
  锚点集 A = I（注入集）∪ F（块内 strand 1..N-1 已融合的 reality）
  S(r) = Σ_{a∈A} w_a · d(r,a) / Σ_{a∈A} w_a      ← 加权平均距离（min 退役）
  ① 排除：S(r) > R → 无关
  ② 排序：S(r) 升序 → 先匹配最近的
  ③ top-K 交 4B decide（prompt 标注 S 顺序）→ merge 目标 | new（宁分不并）
```

**设计要点（用户确认）**：
1. **加权平均替代 min**：min 无法承载 per-anchor 权重；且 min 随锚集增长漂移（R 语义不稳定），加权平均 R 语义稳定
2. **α < β**（注入锚权重低）：注入来自提问（语义猜测，信息有限），融合来自行为事实（可靠）——且**降低注入单点故障**（注入错 → 低权重稀释）
3. **权重可调（精炼轮学习）**：被纠正的 reality 降权（见 §六）
4. **F 锚的鸡生蛋解法**：strand 1 无先行者 → 锚 = I（注入集）——注入正确则 strand 必在其邻域

## 六、per-anchor 权重生命周期

```
初始化：注入进入 I → w_a = 0.4（语义来源，先验低）
        归并确认进入 F → w_a = 0.8（行为事实，先验高）
精炼轮：纠正（strand 从 a 移走 / a 被拆分）→ w_a -= 0.2（下限 0.1）
        复审通过（a 的归并核实无误）        → w_a += 0.1（上限 1.0）
```

数值（0.4/0.8/±0.2）为**先验，待数据校准**（见 §九验证结论）。

## 八、验证结果（2026-08-03，tester 504 strand 为主）

### 8.1 实验方法论修正（重要）

**聚合键错误**：`topic_id` 是 **session 内话题编号**（`topic_manager.py:429` reset 时 `_next_topic_id=1`），非全局块 ID。早期实验按 topic_id 聚合 → **跨 session 假共现 94%**（winker 104 边中 98 条为假，铁证：R1「模型工作流」×R20「事项批准」被算成 w=4）。**正确聚合键 = (session_id, topic_id) 复合键**。

**自锚 bug**：`dist(r,a)` 未处理 r==a（自锚距离应为 0，误返回 1），压低 top1。修复后排名正常。

### 8.2 数据可行性（复合键真实结构）

| profile | strand | 复合块 | 真实共现边 | 延续率 |
|---|---|---|---|---|
| winker | 46 | 41 | 6（w=1） | 0% |
| sysadmin | 57 | 48 | 3（w=1） | 78% |
| **tester** | **504** | **365** | **64**（w≥2 有 8 条） | **57%** |

**tester 是最佳验证集**（数据量、共现密度、延续样本三者兼备）。此前"tester 块不可用"为聚合键错误的产物，已反转。

### 8.3 S 模型验证结果（tester，云端金标准 50 reality）

| 场景 | top1 | top3 | 对照 |
|---|---|---|---|
| 目标 ∈ 锚集（完美注入/延续） | 0.83-0.93 | 0.97-0.99 | 自锚 d=0 主导 |
| **目标 ∉ 锚集（注入漏选，核心场景）** | **0.49** | **0.82** | **随机基线 0.02/0.09** |
| 注入掺错（掺 1 无关） | 0.60-0.61 | 0.89-0.95 | 拉低但不崩溃 |

**核心结论**：共现边在"目标不在锚集"时把相关 reality 拉进 top3 的概率 82%（vs 随机 9%）——**行为信号的验证通过**，模型存在的理由成立。目标与锚无边的 46% 样本 S=∞ → new（宁分不并的正确行为）。

### 8.4 权重 α/β

- 完美注入下权重方向无差异（锚集全对时 α/β 只影响次要项）
- 掺错下 sysadmin 小样本显示 α 高略优（0.68 vs 0.49），tester 几乎无差异——**与"注入锚权重低"假设方向不一致但统计不足**
- **结论：α=0.4/β=0.8 维持先验值 + 精炼轮学习机制，最优值待真实运行数据（注入 4B 拣选落地后）校准**。实验框架（完美注入/掺错 1 个）与真实注入错误形态（该注入的漏选）有差距，权重验证需真实链路数据

## 九、数据约束与发现

1. **winker 46 strand**：复合键后真实共现仅 6 条边（w=1）、延续 0%——**数据量不足以验证共现图模型**，早期结论（基于错误聚合）作废
2. **tester 504 strand**：**最佳验证集**——复合键后 365 块、64 条真实共现边（w≥2 有 8 条）、延续率 57%。云端流式构建金标准 50 reality（7 批，最终 504/504 全覆盖）
3. **sysadmin 57 strand**：48 块、3 条共现边、**延续率 78%**（F 锚场景丰富但共现稀疏）——与 tester 互补（延续 vs 共现密度）
4. **聚合键铁律**：块级共现**必须用 (session_id, topic_id) 复合键**，禁止跨 session 按 topic_id 聚合（假共现 94%）
5. **结论**：共现图核心价值（目标漏选时拉进候选 top3=82%）已验证；α/β 最优值维持先验 + 精炼轮学习，**待真实链路数据校准**
