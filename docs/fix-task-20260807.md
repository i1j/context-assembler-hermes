### P0-2 [D1] tail-protection 按 token 预算实现（高）

- **文件**: `ca/a_stage.py:102-110`（_build_conv_history_v6 tail_set 计算）
- **证据**: 设计 `docs/wiki/decisions/13-tail-protection.md`：「保护最后 CA_PROTECT_TAIL_TOKENS（默认 20000）token 对应的 user 轮，从 turn_stream 末端向前扫描」；`Config.PROTECT_TAIL_TOKENS`（config.py:123-126）定义但全库无消费点。代码硬编码 `user_turns[-2:]`。
- **建议修复**: 用 `Config.PROTECT_TAIL_TOKENS` 从末端 user turn 向前累计 token（Elm 长度估算，如 `len(text)/4` 或字符数）直到达到预算，得到 tail_set；预算未用尽时保护全部。保持 `_row_to_message` 的 in_tail 分支语义不变。
- **验证**: 构造多 turn 测试：短消息（累计 < 预算）→ 全保护；超长单轮 → 至少保护最后 1 轮。检查现有 tests/ 中 tail-protection 相关测试是否仍通过。
